# Standard vs Custom

## Standard ERPNext

- Multi-company setup
- Internal Customer / Internal Supplier mapping
- Price List and Item Price
- Purchase Order
- Partial Purchase Receipts
- Purchase Invoice
- Sales Invoice
- Intercompany Purchase Invoice generation
- Stock Entry / Stock Ledger
- User / Role / User Permission framework
- Attachments and dashboards

## Custom in this app

- Sales Value Confirmation DocType
- Sales Value Confirmation approval workflow
- Sales Invoice validation requiring approved Sales Value Confirmation
- Intercompany Transaction Tracker report
- Custom link field(s), if used for traceability
